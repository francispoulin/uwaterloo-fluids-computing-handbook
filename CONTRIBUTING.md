# Contributing to the Waterloo Fluids Computing Handbook

Thank you for helping improve the handbook.

## How to Contribute

### Report a Problem

Open a GitHub Issue if you find:

- incorrect commands
- outdated software versions
- broken examples
- typographical errors
- unclear instructions

### Suggest Improvements

Open a GitHub Issue describing:

- the problem
- the proposed improvement

Discussion is encouraged before large changes are made.

### Submit a Pull Request

Pull requests are welcome.

Typical pull requests include:

- fixing commands
- correcting typos
- updating software versions
- improving explanations
- adding examples

## Review Process

All changes are reviewed before being merged.

The maintainer has final responsibility for:

- technical accuracy
- style consistency
- organization of the handbook

## Editing Guidelines

When possible:

- keep instructions concise
- prefer copy-and-paste-friendly commands
- avoid multi-line shell commands
- test commands before submitting changes

## PDF Files

Do not edit PDF files directly.

All changes should be made to the source files located in:

```text
handbook/
```
