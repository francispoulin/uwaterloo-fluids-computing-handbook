\section{Linux Navigation}

Most interactions with a Linux server occur through a command-line interface.

\subsection{Where Am I?}

\begin{lstlisting}
pwd
\end{lstlisting}

Example:

\begin{lstlisting}
/home/username
\end{lstlisting}

\subsection{Listing Files}

\begin{lstlisting}
ls
ls -l
ls -lh
\end{lstlisting}

\subsection{Changing Directories}

\begin{lstlisting}
cd project1
cd ..
cd
\end{lstlisting}

Typing \texttt{cd} without an argument returns you to your home directory.

\subsection{Creating Directories}

\begin{lstlisting}
mkdir project1
mkdir code data figures
\end{lstlisting}

\subsection{Useful Shortcuts}

\begin{center}
\begin{tabular}{ll}
\toprule
Symbol & Meaning \\
\midrule
\texttt{.} & Current directory \\
\texttt{..} & Parent directory \\
\texttt{\~} & Home directory \\
\bottomrule
\end{tabular}
\end{center}
