\section{Troubleshooting}

\subsection{Command Not Found}

\begin{lstlisting}
which python
\end{lstlisting}

Verify that the program is installed and available in your PATH.

\subsection{Disk Full}

\begin{lstlisting}
df -h
\end{lstlisting}

\subsection{Permission Denied}

\begin{lstlisting}
ls -l
\end{lstlisting}

Check file ownership and permissions.

\subsection{Program Crashed}

Check:

\begin{itemize}
\item available memory;
\item available disk space;
\item error messages.
\end{itemize}

\subsection{Before Asking for Help}

Include:

\begin{itemize}
\item the command you ran;
\item the full error message;
\item what you have already tried.
\end{itemize}
