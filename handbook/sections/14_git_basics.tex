\section{Git Basics}

Git is a version control system that helps track changes to code and documents.

\subsection{Cloning a Repository}

\begin{lstlisting}
git clone https://github.com/user/repo.git
\end{lstlisting}

\subsection{Saving Changes}

\begin{lstlisting}
git add file.py
git commit -m "Update analysis"
\end{lstlisting}

\subsection{Uploading Changes}

\begin{lstlisting}
git push
\end{lstlisting}

\subsection{Getting Updates}

\begin{lstlisting}
git pull
\end{lstlisting}

\subsection{Exercise} 

Create a new directory called \texttt{git-practice}: 

\begin{lstlisting} 
    mkdir git-practice 
    cd git-practice 
\end{lstlisting} 

Initialize a Git repository: 

\begin{lstlisting} 
    git init 
\end{lstlisting} 

Create a file: 

\begin{lstlisting} 
    echo "Hello Git" > README.txt 
\end{lstlisting} 

Add the file: 

\begin{lstlisting} 
    git add README.txt 
\end{lstlisting} 

Commit the file: 

\begin{lstlisting} 
    git commit -m "Initial commit" 
\end{lstlisting} 

Verify the commit history: 

\begin{lstlisting} 
    git log --oneline 
\end{lstlisting}
