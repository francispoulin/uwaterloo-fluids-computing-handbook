\section{Running Programs}

Most users connect to Pelee and Rondeau in order to run scientific software.

\subsection{Python}

Example file, \texttt{hello.py}, with contents:
\begin{lstlisting}
print("Hello World")
\end{lstlisting}

Run using:

\begin{lstlisting}
python hello.py
\end{lstlisting}

\subsection{Julia}
Example file, \texttt{hello.jl}, with contents:

\begin{lstlisting}
println("Hello World")
\end{lstlisting}

Run using:

\begin{lstlisting}
julia hello.jl
\end{lstlisting}

\subsection{Useful Commands}

\begin{lstlisting}
which python
echo $PATH
\end{lstlisting}
