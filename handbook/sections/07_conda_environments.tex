\section{Conda Environments}

Different projects often require different software versions.

\subsection{Creating an Environment}

\begin{lstlisting}
conda create -n ocean python=3.12
\end{lstlisting}

\subsection{Activating an Environment}

\begin{lstlisting}
conda activate ocean
\end{lstlisting}

\subsection{Installing Packages}

\begin{lstlisting}
conda install numpy
\end{lstlisting}

\subsection{Leaving an Environment}

\begin{lstlisting}
conda deactivate
\end{lstlisting}
