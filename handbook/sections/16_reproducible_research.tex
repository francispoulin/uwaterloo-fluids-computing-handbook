\section{Reproducible Research}

Good research should be easy for others (and your future self) to reproduce.

\subsection{Recommended Project Structure}

\begin{lstlisting}
project/
|-- code/
|-- data/
|-- figures/
|-- notebooks/
`-- manuscript/
\end{lstlisting}

\subsection{Best Practices}

\begin{itemize}
\item Use Git.
\item Use Conda environments.
\item Keep raw data separate from results.
\item Write a README file.
\end{itemize}

\subsection{Exercise}

Create a project directory using the structure above.
