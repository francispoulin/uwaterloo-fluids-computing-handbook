\section{Editing Files}

Many scientific workflows require editing scripts, configuration files, and text files.

\subsection{Using Nano}

Nano is a simple text editor that is available on most Linux systems.

Open a file:

\begin{lstlisting}
nano notes.txt
\end{lstlisting}

If the file does not exist, it will be created.

\subsection{Saving Changes}

To save:

\begin{lstlisting}
Ctrl+O
\end{lstlisting}

Press Enter to confirm.

\subsection{Exiting}

To exit:

\begin{lstlisting}
Ctrl+X
\end{lstlisting}

\subsection{Viewing a File}

Display a file:

\begin{lstlisting}
cat notes.txt
\end{lstlisting}

For longer files:

\begin{lstlisting}
less notes.txt
\end{lstlisting}

Press q to quit.
