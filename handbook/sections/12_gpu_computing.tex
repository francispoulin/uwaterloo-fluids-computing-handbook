\section{GPU Computing}

Many scientific applications can use GPUs.

\subsection{Checking GPU Usage}

\begin{lstlisting}
nvidia-smi
\end{lstlisting}

This displays:

\begin{itemize}
\item GPU memory usage;
\item GPU utilization;
\item running processes.
\end{itemize}

\subsection{Good Practice}

Always check whether a GPU is busy before starting large jobs.

\subsection{Exercise}

Run \texttt{nvidia-smi} and identify the available GPUs.
