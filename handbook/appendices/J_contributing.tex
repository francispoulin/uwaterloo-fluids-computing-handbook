\section{Contributing to This Handbook} 

This handbook is maintained through a public GitHub repository. 

Suggestions, corrections, and improvements are welcome. 

\subsection{Repository} 

The source files for this handbook are hosted on GitHub: 

\begin{lstlisting} 
    https://github.com/francispoulin/ uwaterloo-fluids-computing-handbook 
\end{lstlisting} 

\subsection{Reporting Errors} 

If you discover: 

\begin{itemize} 
    \item incorrect commands; 
    \item broken examples; 
    \item outdated software versions; 
    \item typographical errors; 
    \item unclear instructions; 
\end{itemize} 

please open a GitHub Issue. 

Describe: 

\begin{itemize} 
    \item the section containing the issue; 
    \item the command that was executed; 
    \item any error message; 
    \item a proposed correction (if known). 
\end{itemize} 

\subsection{Suggesting Improvements} 

Suggestions for new sections, tutorials, appendices, and examples are encouraged. Examples: 

\begin{itemize} 
    \item new software packages; 
    \item updated Julia workflows; 
    \item Alliance cluster instructions; 
    \item additional GPU examples. 
\end{itemize} 

\subsection{Submitting Changes} 

Users familiar with Git may submit a pull request. 

All contributions are reviewed before being merged. 

\subsection{Source Files} 

Do not edit the PDF directly. 

All modifications should be made to the source files contained in the repository.
