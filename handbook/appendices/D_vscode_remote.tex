\section{VSCode Remote SSH} 

Many users prefer VSCode instead of terminal editors. 

\subsection{Install} 

Install 

\begin{itemize} 
\item Visual Studio Code 
\item Remote SSH Extension 
\end{itemize} 

\subsection{Connect} 

Open the command palette: 

\begin{lstlisting} 
Ctrl+Shift+P 
\end{lstlisting} 

Select 

\begin{lstlisting} 
Remote-SSH: Connect to Host 
\end{lstlisting} 

and connect to Pelee or Rondeau. 

\subsection{Benefits} 

\begin{itemize} 
\item graphical file browser; 
\item interactive terminal; 
\item syntax highlighting; 
\item Git integration. 
\end{itemize}
