# Waterloo Fluids Computing Handbook

The Waterloo Fluids Computing Handbook provides onboarding and reference material for students and researchers using the University of Waterloo Fluids Lab computing resources.

Topics include:

- Linux
- Git
- Environment Modules
- Python Virtual Environments
- Conda
- Jupyter
- tmux
- Julia
- Python
- CUDA
- MPI
- Multi-GPU Computing
- Alliance Clusters

## New Students

New students should begin with the handbook PDF located in the `release/` directory.

The handbook is designed to take a new user from:

```
No Linux experience
```

to

```
Running Julia and Python workflows on CPUs and GPUs
```

within a few hours.
